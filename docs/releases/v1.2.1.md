# Search Your Gits 1.2.1 · 寻迹

本次加入 GitHub 登录和 Star 收藏同步，并精简 Windows 安装包。

## 更新内容

- 新增 GitHub 设备授权登录，左下角集中账号、设置和反馈入口；支持公开资料与自己的公开仓库分页。
- “我的收藏”改为当前账号的 GitHub Star，榜单、搜索、账号页及详情中的收藏／取消收藏同步 GitHub；未登录引导授权，旧本机收藏保留且不自动批量上传。
- 登录凭据使用 Windows 安全存储加密，支持续期、退出清理、账号隔离、限流缓存与 Star 写入失败保护。
- 精简安装包：仅保留简繁中文及英文语言包，移除依赖调试文件和桌面端不使用的邮件服务依赖，解压目录约从 356 MB 降至 308 MB；保留完整运行环境与许可证。
- 增强安装包内容检查，补充 GitHub 登录配置、收藏同步及体积审计说明。

## 下载与升级

Windows 10 / 11 x64 用户下载 **Search-Your-Gits-Setup-1.2.1-x64.exe**，运行中文安装向导。无需安装 Node.js、Python 或 Git。升级沿用原应用 ID，保留设置与本机数据。

**Search-Your-Gits-Source-1.2.1.zip** 是开发者源码；**SHA256SUMS.txt** 用于校验附件完整性。

登录入口在左下角“更多 → 登录 GitHub”，复制软件显示的验证码，到 GitHub 官方网页完成授权。软件不会收集 GitHub 密码，不要求普通用户填写 Client ID。收藏使用 GitHub 的 Star；本次不支持私有仓库收藏。旧本机收藏不会自动批量加星。列表缓存 5 分钟，点击刷新可立即尝试同步网页端改动。

1.1.3 及以上客户端可通过常驻检查更新或设置中的立即检查发现 1.2.1，并前往本页下载升级；自动检查间隔为 6 小时。当前采用网页下载安装，不静默替换运行中的程序。

## 验证与说明

88 项自动测试通过；独立 Electron 界面检查覆盖设备授权模拟、凭据加密、收藏增删、分页、账号退出和失败保护。真实 GitHub 账号仍需用户自行完成网页授权。运行环境精简前后，打包 EXE 启动与榜单/设置页检查通过。

联网能力仍依赖 GitHub 及各内容来源的可用性、权限与额度；不内置共享用户 Token 或付费翻译密钥。安装器未使用代码签名证书，请从本仓库 Release 下载。
