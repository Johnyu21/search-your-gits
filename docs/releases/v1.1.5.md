# Search Your Gits 1.1.5 · 寻迹

本次增加更多项目发现方式，并明确周榜、月榜和季度榜的数量来源。

## 更新内容

- 新增独立 **扩展发现榜**：筛选近 7 / 30 / 90 天有推送的公开、非 Fork、未归档且至少 1 Star 的项目，按 Star 总数倒序，支持 Top 25 / 50 / 100、语言及关键词筛选。
- 扩展发现榜与真实增长榜分开，不用 Star 总数或近期活跃冒充周期增长；项目列显示最近推送日期。
- 周榜、月榜显示来源返回数、筛选后数量和实际展示数，明确 Top 25 / 50 / 100 是展示上限。来源只有 13 个项目时，保留真实数据并提供扩展发现入口。
- 季度增长榜说明本机跟踪数、具备至少两个日期快照的仓库数与筛选结果；历史不足时可直接前往扩展发现榜。
- 缓存保留来源数量，旧缓存会尝试刷新获取数量信息；失败仍保留旧数据。搜索结果不完整时显示提示，总数标为暂估。

## 下载与升级

Windows 10 / 11 x64 用户下载 **Search-Your-Gits-Setup-1.1.5-x64.exe**，运行中文安装向导。无需另装 Node.js、Python 或 Git；升级保留收藏、设置和本机数据。

开发者源码为 **Search-Your-Gits-Source-1.1.5.zip**；**SHA256SUMS.txt** 用于校验附件完整性。

已安装 1.1.3 / 1.1.4 的用户可点击常驻“检查更新”或设置中的“立即检查”；开启自动检查时，启动后及每 6 小时检测新版本。提醒会打开本 Release 页面，下载后运行安装包完成升级。当前不是静默在线安装。

## 验证与数据说明

72 项自动测试与真实 Electron 界面联调通过；三个周期均已通过实际 GitHub Search API 获取 100 条项目并核验 Star 倒序，打包程序的 Top 100 联网展示通过。

GitHub Trending 本身不保证固定返回 25 / 50 / 100 个项目。季度增长仍依赖本机快照；扩展发现榜按推送日期筛选，不能表示对应周期新增 Star。网络或来源限流时仍可能需要等待、读取缓存或配置自己的 GitHub Token。安装器暂未使用代码签名证书，请从本仓库 Release 下载。
