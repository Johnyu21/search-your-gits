# Search Your Gits 1.2.3 · 寻迹

本次修复 AI 工具中的模型能力天梯数据错位。

## 更新内容

- 修复能力天梯来源表格调整列序后，将 Time per Task 耗时误读为能力分数、价格误读为厂商的问题。
- 按实际叶级表头识别模型、Intelligence Index 评分和上下文，厂商读取对应列或模型徽标；保留分数降序、同分来源顺序及连续编号。
- 隔离旧解析器生成的错误缓存，联网刷新绕过 HTTP 缓存；更新失败只回退新解析器的有效缓存，不再显示旧错误评分。
- 新增真实来源页面精简样本、列序变化、缺失评分列及缓存迁移回归，96 项测试及桌面回归通过。

## 下载与升级

Windows 10 / 11 x64 用户下载 **Search-Your-Gits-Setup-1.2.3-x64.exe**，运行中文安装向导。自带运行环境，无需安装 Node.js、Python 或 Git；升级保留设置、GitHub 登录、本机数据及收藏缓存。

升级后进入 **AI 工具 → 能力天梯 → 立即刷新**。旧解析器的错误缓存不会复用；如果首次更新时无法连接来源，会明确提示不可用，不将旧错误数值冒充最新能力评分。

**Search-Your-Gits-Source-1.2.3.zip** 是开发者源码，**SHA256SUMS.txt** 用于核对文件完整性。已有支持更新检测的客户端可点击常驻“检查更新”，或等待自动检查；通过本 Release 下载安装升级。

## 验证与数据口径

96 项单元测试通过；使用实际来源 HTML 成功解析 69 条有效评分，并核验按分数降序及字段归属。开发界面使用该实际页面快照的 Top 20 展示检查和既有桌面回归通过。回归样本仅用于测试，运行中的榜单仍从 Artificial Analysis 读取，不内置固定模型排名。

能力榜来自 [Artificial Analysis Intelligence Index](https://artificialanalysis.ai/leaderboards/models)，不同推理档位分别列出；分数不代表准确率或适合所有任务。来源内容和可用性仍可能变化，数据时间以界面标注为准。安装器未使用代码签名证书，请从本仓库 Release 下载。
