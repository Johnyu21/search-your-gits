# Search Your Gits 1.1.4 · 寻迹

本次主要改进项目搜索、榜单排序和日常操作。

## 更新内容

- 项目搜索默认使用“精准匹配”：完整仓库名与完全同名优先，同等匹配按 Star 总数倒序；支持空格与连字符差异、同名候选补充、去重与缓存。另保留 Star 最多、最近更新排序。精准重排范围为当前页与最多 100 个同名补充候选。
- 热门增长榜默认在 Trending 候选中按 Star 总数倒序，可切换周期增长最多或来源默认顺序。先排序再截取 Top，切换顺序复用候选缓存；季度榜也支持 Star 或观测净增长排序。
- 项目详情顶部固定“在 GitHub 打开”“复制仓库链接”和关闭按钮，无需滚动到底；资讯详情隐藏仓库专属操作。
- 设置新增 MADE BY FUTURE 启动画面开关，默认开启；关闭并保存后直接进入主界面，不再等待 3 秒。页面切换动画独立设置。
- 更换壁纸、调整启动画面及其他需显式保存的配置后，底部显示约 3 秒的保存提醒，提示对应保存按钮。

## 下载与升级

Windows 10 / 11 x64 用户下载 **Search-Your-Gits-Setup-1.1.4-x64.exe**，运行中文安装向导。无需另装开发环境；升级保留收藏、设置和本机数据。

**Search-Your-Gits-Source-1.1.4.zip** 供开发者使用，普通用户不需要下载。可用 **SHA256SUMS.txt** 核验下载完整性。

已安装 1.1.3 的用户可点击客户端常驻“检查更新”，或在设置中“立即检查”；自动检查最长间隔为 6 小时。提醒会打开本 Release 页面，下载后运行安装包完成升级。1.1.4 不会重复提示自身版本；更旧的 1.1.2 需手动下载升级。

## 验证与说明

68 项自动测试、真实 Electron 界面联调和本地安装版代码核验通过。覆盖排序切换、缓存回退、Top 截断、搜索、详情操作、启动设置及保存提醒。

榜单排序仅针对当前来源候选，季度数据来自本机历史快照；并非全站 Star 排名。安装器暂未使用代码签名证书；请从本仓库 Release 下载。
