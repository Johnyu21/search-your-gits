# Search Your Gits 1.2.2 · 寻迹

修复收藏写入失败和取消后项目仍显示的问题，增加取消收藏确认。

## 更新内容

- 修复真实 Electron 网络层手动 Content-Length 导致收藏报 net::ERR_INVALID_ARGUMENT：改为空请求体，由网络层正确生成长度。
- 默认使用 OAuth App 设备授权并申请 public_repo 范围，修复旧 GitHub App 授权对任意公开仓库 Star 写入的集成访问限制；保留旧会话升级入口和账号缓存隔离。
- 所有取消收藏入口统一在主进程显示确认窗口，默认保留；关闭或按 Esc 不发送取消请求，确认期间账号变化也不会误改其他账号。
- 修复取消成功后强制刷新仍命中 Chromium HTTP 缓存、旧列表让项目重新出现的问题；账号请求绕过 HTTP 缓存，保留可控的应用层缓存与离线回退。
- 区分集成访问限制、一般权限拒绝和无 Retry-After 的二次限流；失败不显示成功、不修改已确认状态。
- 增加真实 Electron 请求构造与 HTTP 缓存回归，并纳入 CI 和打包前检查；更新 OAuth 注册和升级说明。

## 下载与升级

Windows 10 / 11 x64 下载 **Search-Your-Gits-Setup-1.2.2-x64.exe**，运行中文安装向导；自带运行环境，无需安装 Node.js、Python 或 Git。升级保留设置与本机数据。源码为 **Search-Your-Gits-Source-1.2.2.zip**，校验文件为 **SHA256SUMS.txt**。

### 旧账号需要一次授权升级

如果之前用 GitHub App 登录：安装 1.2.2 后打开 **左下角账号菜单 → 我的 GitHub → 升级收藏授权**，复制验证码，在 GitHub 官方网页授权。新用户直接点击“登录 GitHub”。无需用户注册应用、填写 Client ID 或分享 Token。已经使用新 OAuth 登录的用户不需要重复授权。

OAuth 申请 **public_repo** 用于公开仓库收藏；GitHub 的此范围也包含部分公开仓库写权限，请在官方授权页查看。程序不申请私有仓库或管理权限。

取消收藏会弹出确认，默认“保留收藏”，按 Esc 或关闭窗口不取消；成功后从收藏列表同步移除。旧本机收藏数据保留，不自动批量加星。

现有支持更新提醒的客户端可点击常驻“检查更新”或设置中的“立即检查”；自动检查每 6 小时运行。本次仍通过 Release 页面下载并运行安装器升级，不静默替换程序。
