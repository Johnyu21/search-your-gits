# 1.1.3 开发验证

日期：2026-10-24（Asia/Shanghai）。本次修改本地源码并生成 1.1.3 本地验收安装包，不改写已发布的 1.1.2 安装包或 GitHub Release。

## 验证范围

- 61 项 Node 自动化测试通过：包含原有价格、登录、榜单、反馈服务与启动入口回归，以及新增冷却跨重启、短等待重试、详情离线缓存、分片续传、同名搜索、翻译协议、更新版本筛选与 IT之家日期解析。
- 真实公开 GitHub 请求：Search Your Gits 最佳匹配返回 291 个候选，Johnyu21/search-your-gits 位于本程序结果第 1 位并标记完全同名（当次返回快照，未来 GitHub 数据和限流可能变化）。
- 真实 IT之家人工智能栏目返回并解析 30 条资讯；已验证标题、摘要、文章域名和北京时间。
- Electron 实际桌面联调使用隔离用户目录及可控 HTTP 响应，执行列表原文/中文切换、同名项目、详情关闭、README 展示、翻译配置验证、Token 获取链接和额度检查、Release 提醒、GitHub Issue 草稿、版本规则删除、限流倒计时与跳转设置。未使用普通用户数据，未提交真实 Issue 或发送邮件。
- 修复并验证 Electron contextBridge 对 Error 自定义字段的丢失，改为结构化响应并在渲染进程构造错误，保留 code/retryAt；倒计时在真实 IPC 通路中可见。

## 约束

默认公共翻译仍受第三方额度约束；自建翻译和兼容模型协议以本地模拟响应验证，未使用真实付费密钥。首次安装无历史缓存时仍依赖网络，不能保证所有地区无需 Token 即无限使用。邮件自动投递尚未部署公网服务，默认采用 GitHub 反馈并需要用户最终确认公开发布。

更新检查只发现公开 Release；测试中的 1.1.4 是隔离模拟版本，并非已发布版本。当前采用网页下载安装，没有静默在线更新。旧 1.1.2 客户端没有检测功能，首次升级需手动下载安装。

桌面联调可复现命令：`npm run test:desktop`。使用独立临时配置、合成 Token 和模拟下一版本，不会访问真实登录凭据或执行真实反馈提交。另已验证限流到期后自动请求并恢复列表、翻译限流提示，以及深色/窄窗口显示。

## 本地打包

`npm run dist` 成功，61 项测试通过，生成 1.1.3 x64 NSIS 安装器、白名单源码 ZIP 和 SHA256SUMS.txt。安装器大小与哈希以本次 release/1.1.3 文件及 SHA256SUMS.txt 为准；ASAR 含 1210 项，新增主进程、预加载、界面和请求模块逐一与源码比较一致，运行包未包含 server、test、scripts 或私密环境文件。

打包后实际启动 win-unpacked/Search Your Gits.exe，使用独立 --user-data-dir，确认 3 秒启动流程后进入 1.1.3 主界面、翻译设置存在、无邮件地址时反馈按钮可用且为 GitHub 入口。此项为打包程序启动验证，本轮未在日常用户环境重新安装或卸载，避免改动现有快捷方式和注册信息。GitHub Release 未更新。

简介语言改为标题旁约 96×28 像素的中文｜原文分段按钮，移除单独工具栏。Token 输入/输出表头支持升降序，排序下拉同步；桌面联调验证零价格正常排序、缺失报价始终在最后。侧栏更新入口跨页面保留，顶部提示关闭后仍显示新版本；小窗口移至视口右下角，已验证页面滚动后仍在可视范围。维持 1.1.3，不修改 CHANGELOG，重新生成本地安装包供验收。
