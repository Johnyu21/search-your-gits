维护者：配置 GitHub 登录应用

只需软件维护者注册一次 OAuth App；普通用户点击登录并授权即可。

如何获取 GitHub Token？
  1. 打开下方获取页面并登录自己的 GitHub 账号。
  2. 名称填写 Search Your Gits，有效期建议 90 天。
  3. Repository access 选择 Public repositories，权限保持默认。
  4. 点击 Generate token，复制后粘贴到上方并保存。

Token 仅加密保存在本机，不要分享给别人。软件不能未经授权自动生成 Token。

关闭程序后不采集；同一天只保留最近一次快照。

AI 工具与成本口径
工具页可查看 OpenRouter、硅基流动公开报价以及登录 CloseAI Asia 后同步的账户模型报价，支持每 5 分钟检查与手动刷新。成本分析按普通输入、缓存输入、输出 Token 分项计算，汇率为手动假设。用量账本为本机手工记录，不是供应商账单。能力天梯来自 Artificial Analysis 的公开指标，不代表所有任务表现；公告只展示官方公开动态，不推测个人额度。缓存、来源条件与获取时间在工具内单独标明。
独立项目搜索与中文介绍
开源项目搜索面向 GitHub 全站公开仓库，不限定创建日期，支持 GitHub 搜索语法、语言与排序。普通结果每页 30 条，精准优先会额外补入最多 100 个同名候选，并优先展示完全同名仓库；同等匹配按 Star 数倒序（当前页与补充结果内）；最多浏览 GitHub 前 990 条普通结果。项目详情会优先显示中文介绍；机器翻译使用设置中所选服务，仅发送公开介绍文本，不发送 GitHub Token。翻译缓存保存在本机，原文始终保留。翻译失败时会明确提示，可选择原文语言后重试。
行业资讯
汇总国内外计算机与 AI 行业资讯，按地区、行业筛选和发布时间排序。列表和摘要页隐藏站点及网址来源信息，保留阅读原文入口。资讯连接失败时会显示缓存或提示稍后重试。
扩展发现榜 · 独立榜单
使用 GitHub Search API，筛选近 7 / 30 / 90 天有推送的公开、非 Fork、未归档且至少 1 Star 的仓库，按当前 Star 总数排序，可选 Top 25 / 50 / 100。它提供更多近期活跃项目，不是周期 Star 增长排行，不会补入真实周榜、月榜或本机季度增长榜。语言和关键词可进一步筛选；没有匹配时不会凑数。
周 / 月热门榜
来自 GitHub Trending，默认在来源候选中按 Star 总数倒序，可切换周期增长最多或来源默认顺序。增长列是页面提供的周期 Star 增量；来源顺序并非简单按 Star 或增量排序。通常返回约 25 个项目，Top 100 不会补造数据。
季度热门榜 · 本机观测
统计近 90 天中，本机已跟踪仓库的首末 Star 快照差值，可按 Star 总数或观测净增长排序。至少有两个不同 UTC 日期的快照才会入榜。每行显示实际覆盖天数；不足 90 天时仅代表这段观测期。不同仓库的观测期可能不同，不能视为完整、全站的官方季度榜。
候选项目来自已查看的榜单、详情和收藏；只在程序运行期间采集。首次使用通常为空，后续日期继续采集后才有排名。季度榜点“刷新”只重算本地数据；在设置中点“立即采集快照”更新 Star。
周 / 月 / 季度新项目榜
使用 GitHub Search API，分别筛选近 7 / 30 / 90 天创建的公开、非 Fork、未归档仓库，按当前 Star 总数排序。它衡量新仓库热度，不表示这段时间增加的 Star。
