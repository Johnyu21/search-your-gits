数据来源与功能说明
AI 工具与成本口径
工具页可查看 OpenRouter、硅基流动公开报价以及登录 CloseAI Asia 后同步的账户模型报价，支持每 5 分钟检查与手动刷新。成本分析按普通输入、缓存输入、输出 Token 分项计算，汇率为手动假设。用量账本为本机手工记录，不是供应商账单。能力天梯来自 Artificial Analysis 的公开指标，不代表所有任务表现；公告只展示官方公开动态，不推测个人额度。缓存、来源条件与获取时间在工具内单独标明。
独立项目搜索与中文介绍
开源项目搜索面向 GitHub 全站公开仓库，不限定创建日期，支持 GitHub 搜索语法、语言与排序。每页 30 条，最多浏览前 990 条。项目详情会优先显示中文介绍；机器翻译通过 MyMemory 提供，仅发送公开介绍文本，不发送 GitHub Token。翻译缓存保存在本机，原文始终保留。翻译失败时会明确提示，可选择原文语言后重试。
行业资讯
汇总国内外计算机与 AI 行业资讯，按地区、行业筛选和发布时间排序。列表和摘要页隐藏站点及网址来源信息，保留阅读原文入口。资讯连接失败时会显示缓存或提示稍后重试。
周 / 月热门榜
来自 GitHub Trending，保留官方页面顺序。增长列是页面提供的周期 Star 增量；官方热门排序不等于按增量简单排序。通常返回约 25 个项目，Top 100 不会补造数据。
季度热门榜 · 本机观测
统计近 90 天中，本机已跟踪仓库的首末 Star 快照差值，按净增长排序。至少有两个不同 UTC 日期的快照才会入榜。每行显示实际覆盖天数；不足 90 天时仅代表这段观测期。不同仓库的观测期可能不同，不能视为完整、全站的官方季度榜。
候选项目来自已查看的榜单、详情和收藏；只在程序运行期间采集。首次使用通常为空，后续日期继续采集后才有排名。季度榜点“刷新”只重算本地数据；在设置中点“立即采集快照”更新 Star。
周 / 月 / 季度新项目榜
使用 GitHub Search API，分别筛选近 7 / 30 / 90 天创建的公开、非 Fork、未归档仓库，按当前 Star 总数排序。它衡量新仓库热度，不表示这段时间增加的 Star。
缓存、搜索与凭据
榜单缓存有效期 1 小时，“刷新榜单”会强制联网。联网失败时有缓存则显示旧数据和更新时间，否则显示错误。热门榜搜索仅筛选当前 Trending 候选；新项目榜支持 GitHub 仓库搜索语法。季度榜和收藏搜索在本机进行。
Token 通过 Windows 安全存储加密，只向 api.github.com 发送。收藏属于本程序，不会操作您的 GitHub Star。CSV 采用 UTF-8 BOM，可用 Excel 打开；同时导出说明文件记录筛选口径和数据时间。
